# Week 3 Challenge - Insurance Risk Analytics

This repository contains code, notebooks, and documentation for the AlphaCare Insurance Solutions risk analytics and predictive modeling challenge.

## Structure
- `data/` — raw and processed datasets
- `notebooks/` — Jupyter notebooks for EDA, modeling, and reporting
- `src/` — source code for data processing and modeling
- `models/` — saved model artifacts
- `reports/` — interim and final reports

## Setup
Install dependencies:
```
pip install -r requirements.txt
```

## Tasks
- Task 1: EDA & Stats
- Task 2: Data Version Control (DVC)
- Task 3: Hypothesis Testing
- Task 4: Statistical Modeling

See the challenge instructions for details.
